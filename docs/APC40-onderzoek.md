# APC40 mkII voor DJ'en: onderzoek (23 september 2026)

Aanleiding: Clay vond de indeling met mapjes (B3) "nog niet echt logisch" en
wil meer vanuit de controller denken. Drie onderzoeksagenten: bestaande
mappings, DJ-conventies, fysieke indeling. Bronnen staan per punt.

## 1. Wat DJ's het meest gebruiken (afgeleid, geen meting)
1. kanaalfader · 2. play/cue · 3. LOW-EQ (bass swap) · 4. filter (één
bipolaire knop) · 5. koptelefoon-cue (PFL) · 6. sync/tempo · 7. hotcues
(daarna loops) · 8. trim (eens per nummer) · 9. crossfader (bij house/techno
ondergeschikt) · 10. FX, sampler, beat jump.
Bronnen: digitaldjtips.com/rock-the-dancefloor/five-basic-dj-transitions,
virtualdj.com/articles/dj-controller-mapping-guide.

## 2. Conventies
- Kanaalstrip van boven naar onder: TRIM → HI → MID → LOW → FILTER → CUE →
  FADER (Pioneer DJM, Traktor S4, Xone). Onderste EQ-knop = bas; spiergeheugen.
- Eén kolom = één deck ("spatial mapping"): de knop boven een fader hoort bij
  die fader. Consistent over alle kolommen.
- De kern (fader, play/cue, EQ, filter, pitch) nooit achter shift of een laag.
- Shift alleen voor secundair/zeldzaam: wissen, grid, tweede bank.
- Padmodi met eigen, oplichtende modusknoppen naast de pads, een vaste kleur
  per modus. Niet via shift.
- Lagen zonder zichtbare stand verwarren; klacht nummer één bij bestaande
  APC40-mappings ("te veel modifiers").
Bronnen: virtualdj.com/manuals/hardware/pioneer/ddjrev1/layout/mixer.html,
maps.djtechtools.com/mappings/24 en /8993, NI S4 MK3-handleiding.

## 3. Bestaande APC40-mappings
- VirtualDJ (officieel): APC als sampler + FX + transport voor één gekozen
  deck (PAN kiest links/rechts). Geen mixer. Nudge = bend, Tap = sync,
  Metronome/Tap/Nudge = loop in/uit/verschuiven in loopmodus.
  virtualdj.com/manuals/hardware/akai/apc40mkii/other.html
- Traktor (community): 4-deck-mixer. Bovenste knoppen = EQ/filter per deck,
  device knobs = FX, grid = 8 hotcues per deck in kolommen met een eigen kleur
  per deck. Meest geprezen: "Corporate Dread" (maps.djtechtools.com/mappings/4223).
- Terugkerend: faders = volume, crossfader = crossfader, device knobs = FX,
  grid = hotcues per kolom, Nudge = tempo-bend, Shift = tweede laag.
- Mixxx, Rekordbox, Serato, djay: geen eigen mapping.

## 4. Fysieke indeling (User Guide v1.0 p4, uitvergroot)
Per kolom van boven naar onder: knob (LED-ring) · 5 grid-pads · Clip Stop ·
Track Select · 2×2-blok [Activator | A/B] boven [Solo | Rec Arm] · fader.
Rechts van het grid: scene launch (5, RGB), Stop All Clips, Master, Cue Level
(naast de 2×2-blokken), masterfader.
Rechterdeel van boven naar onder: [Pan Play Record Session] / [Sends Metronome
Tap (TEMPO)] / [User Nudge− Nudge+]; device knobs 2×4 (LED-ringen); daaronder
[Device◀ Device▶ Bank◀ Bank▶] / [On/Off Lock Clip/Dev Detail]; linksonder de
vier pijlen, rechts daarvan Shift en Bank; rechtsonder de crossfader.
De 16 knoppen met ring zijn eindeloos maar sturen ABSOLUTE waarden (soft
takeover blijft nodig bij wisselen). Tempo en Cue Level zijn relatief.
Bron: cdn.inmusicbrands.com/akai/attachments/apc40II/APC40 mkII - User Guide - v1.0.pdf
